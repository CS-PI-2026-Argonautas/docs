Documentação do projeto de CS, PI, ARPS e IHC


## Visualização dos protótipos

- **VS Code:** Instale a extensão [Excalidraw](https://marketplace.visualstudio.com/items?itemName=pomdtr.excalidraw-editor) e abra o arquivo na pasta "/prototipos"
- **Site do Excalidraw:** Acesse o site [excalidraw.com](https://excalidraw.com), aperte Ctrl + O (ou Open no menu lateral) e selecione o arquivo
